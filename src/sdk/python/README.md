# agent-state-storage (Python)

Python client for AgentStateStorage's `agentstate.v1` gRPC service, plus integrations for the OpenAI Agents SDK and LangGraph.

```bash
pip install -e "src/sdk/python[openai-agents,langgraph]"
kvstore-node --grpc-port 7000 --state-dir ./agent-state
```

```python
from agent_state_storage import Client, Record

with Client("localhost:7000", tenant="acme") as c:
    c.append_items("sess-1", [b"hello"])
    c.write_records([Record(b"k", b"v")])
    c.put_blob("workspace.tar", open("workspace.tar", "rb"))
```

`AsyncClient` has the same methods as coroutines. With mTLS pass `tls=TlsConfig(ca=..., cert=..., key=...)`; the server then takes the tenant from the client certificate.

Tests run against a real node: build `kvstore-node`, then

```bash
KVSTORE_NODE_BIN=build/kvstore-node/kvstore-node pytest src/sdk/python/tests
```

The stubs in `agent_state_storage/_proto/` are generated by `scripts/gen_python_proto.sh`.
